# Real-World Data Cleaning Pipeline

## 📌 Project Overview

This project focuses on cleaning, validating, and analyzing a real-world retail dataset using Python. It identifies missing values and duplicate records, handles missing product descriptions, validates the cleaned data, and generates visualizations to understand country-wise records and monthly sales revenue.

## 🎯 Objectives

- Identify and analyze missing values.
- Detect and remove duplicate records.
- Handle missing product descriptions.
- Inspect unusual quantity and price values.
- Validate the cleaned dataset.
- Analyze country-wise records.
- Calculate monthly sales revenue.
- Generate visualizations using Matplotlib.

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Excel / CSV
